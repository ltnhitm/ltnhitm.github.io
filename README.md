# Lam Tei Elderly & Nursing Home Dashboard Prototype

Static HTML5 + CSS3 + JavaScript prototype for GitHub Pages.

## Views

1. Operation View
2. Professional View
3. KPI View

## Colour palette

Based on the supplied Lam Tei elderly home colour palette:

- Gold: `#CEAD60`
- Dark Gold: `#C1A259`
- Cream: `#E4E7D7`
- Green: `#6CA75E`
- Deep Green: `#004B41`
- Teal: `#0D655B`
- Optional accent orange: `#ED6C00`

## Run locally

Open `index.html` directly in a browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js`.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.

Your demo will be available at:

`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

## Recommended display

- Chrome or Microsoft Edge
- 1920 × 1080
- Full-screen / kiosk mode
